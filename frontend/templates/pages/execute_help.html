Help

Execute is the race-day EOC workspace. Import a Day Plan, then work from Operations, Participants, and Cases.

Plans

Import a published Day Plan ZIP. Import does not activate. Activate one plan to open it on Operations, Participants, and Cases. Archive keeps records and turns volunteer sheet URLs off. Restore does not activate.

Operations

The map is the command surface. Use layers for courses, turn-arounds, resources, SOS, the reopen set, and Water / aid / extract. Closed, Reopen next, and Reopened list locations in the current map view. Set Operator so reopen and assignment actions are attributed.

Participants

Import a Race Roster CSV for the races on this Day Plan. The required column is Participant ID. Search by bib or name, then start a case from a start row. If the table is empty, download the sample on that page and import it.

Cases

Cases are the EOC record of what was reported. Assigned to is the on-course care agency, not ticket ownership. Transfer of care is a handoff between agencies. Call 911 and Mark Urgent are flags on the case header. Outcome, including DNF, is recorded when the case is closed.
