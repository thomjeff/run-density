{# Issue #817: Junction Flow authoring (package-scoped) #}

Junctions

Place a pin on the courses map. Segments whose start or end is within 10 m are listed. Author stream interactions (cross / merge) between streams at the pin. Requires course segments from recipes.

Build race exports / apply recipes so this package has course segments before authoring junctions.

Saved

    Click Place pin on map (button highlights), then click the map — including on course lines. Lat/lon fill automatically; then matching segments load. Drag the pin anytime to reposition — nearby segments refresh after the move. Stream labels and interaction connectors draw on the map from nearby segments.

    Segments

    Full 2nd corridor pass (same geometry, later race km)    Spur leave/return (e.g. 10k university)

    Stream Interactions

    Type Turn From To Conflicts with Description Events Actions

    Table is read-only until you edit a row. Cross: From → To + Conflicts with. Merge: From → one or more To segments (multi-select); Conflicts unused. Turn: left/right as the runner turns. Description: editable plain-language summary (auto-filled from streams; edit while the row is in edit mode, then Save junctions). Events: all events involved in the conflict. Changes stay local until Save junctions.
